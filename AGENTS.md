# Workspace Agent Instructions

## Premium Landing Page Design

Para tarefas envolvendo landing pages, páginas de marketing, hero sections, waitlists, interfaces premium, auditoria visual ou páginas da Link Help:

1. Leia `.agents/skills/premium-landing-page-design/SKILL.md`.
2. Siga seu workflow e checklist.
3. Reutilize o design system existente.
4. Preserve funcionalidades.
5. Valide responsividade e acessibilidade.
6. Não invente métricas, avaliações, parceiros ou depoimentos.
7. Produza um relatório das alterações.
