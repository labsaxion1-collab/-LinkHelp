# Backgrounds das Heroes de clientes

Esta pasta deverá conter os seguintes arquivos:

- `hero-background-new-client.png`
- `hero-background-trusted-client.png`
- `hero-background-gold-client.png`
- `hero-background-diamond-client.png`
- `hero-background-elite-client.png`

Os arquivos devem conter somente o fundo da Hero, sem medalha, pedestal, partículas ou textos. Todos os assets devem usar o formato PNG, com fundo transparente quando aplicável.
