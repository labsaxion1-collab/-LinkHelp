# Backgrounds das Heroes de helpers

Esta pasta deverá conter os seguintes arquivos:

- `hero-background-new-helper.png`
- `hero-background-trusted-helper.png`
- `hero-background-professional-helper.png`
- `hero-background-elite-helper.png`
- `hero-background-top-helper.png`
- `hero-background-legend-helper.png`

Os arquivos devem conter apenas o fundo da Hero, sem medalha, pedestal, partículas ou textos. Todos os assets devem usar o formato PNG, com fundo transparente quando aplicável.
